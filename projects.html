RoadRescue

A web-based vehicle breakdown assistance system that helps users find nearby mechanics during unexpected vehicle trouble. The goal is to make roadside assistance simple, accessible and reliable.

  • Finds available mechanics nearby using location-based services
  • Lets users send service requests and track their status
  • Lets mechanics view, accept or reject requests based on availability
Laravel MySQL PHP

Indian Urban House Price Prediction

A machine learning project that predicts residential property prices in Indian urban areas from features such as location, size and number of bedrooms. The aim is to understand what drives house prices and to estimate them from historical data.

  • Cleaned and prepared housing data by handling missing values, duplicates and inconsistencies
  • Explored the data to find patterns and relationships between property features and prices
  • Trained and evaluated a model to predict house prices from property details
Python Flask Pandas NumPy Scikit-learn
